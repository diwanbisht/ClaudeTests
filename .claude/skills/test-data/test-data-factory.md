# 🏭 Test Data Factory

## 🎯 Purpose

The Test Data Factory provides a **centralized mechanism** to:

- Generate dynamic test data
- Fetch data from external sources (DB, API, CSV, JSON)
- Standardize data structures across tests
- Enable reusable and scalable test data creation
- Support AI-driven test generation
